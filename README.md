# 🩺 Chatbot (Medical Assistant)

A medical chatbot built using Streamlit, FAISS for vector storage, and Hugging Face's Mistral-7B LLM to answer user questions based on context-relevant medical documents.

---

## 🚀 Features

- Chat UI powered by **Streamlit**
- Embedding generation using **`sentence-transformers/all-MiniLM-L6-v2`**
- Retrieval with **FAISS vector store**
- LLM-powered response generation via **Hugging Face Inference API**
- Custom prompt template to ensure grounded, contextual responses
- Keeps chat history in session for an interactive experience
